# Barracuda Dash Settings

Web app for setting up the Barracuda digital gauges over Bluetooth: data sources (analog, OBD, CAN), the CAN sniffer and decoder, lighting, warnings, speed and odometer, sender calibration, units and backups.

Open it at the GitHub Pages address for this repository, in Chrome or Edge (Android, Windows, Mac, Linux). On iPhone or iPad use the Bluefy browser, because Safari has no Web Bluetooth. With no Bluetooth available it opens a demo with a simulated car.

Talks to the speedo gauge with phone protocol 2 (gauge firmware with wired CAN support).
